# Restro Menu#
 🍴 RESTRO – The Art of Fine Dining
 ## 📌 1. Project Overview

Restro is a single-page restaurant website concept designed to give visitors a strong first impression and make the restaurant's main information easy to explore.
The landing page focuses on three things:
 - Visual appeal: A dark overlay, food photography, and orange highlights create a warm restaurant atmosphere.
 - Clear navigation: Visitors can quickly identify the Home, About, Food, Bookings, Services, and Contact sections.
 - Strong first impression: A headline, short introduction, food image, and Book Table button form the main hero section.
    The project is developed using only HTML and CSS, keeping the structure simple and easy to understand.
## 📂 2. Project Structure
Keep the file project arranged in the following structure so that the linked stylesheets and images load correctly:

- test.html: Contains the website structure, navigation bar, hero section, text, and food image.
- style.css: Controls the layout, colors, typography, image styling, background, and animation.
- images/bg-hero.jpg: provides the background image for the landing page.

## 🚀 3. Project Features

  **A. Navigation Bar**
 - Restaurant logo with a cutlery icon.
 - Six navigation links: Home, About, Food, Bookings, Services, and Contact.
 - Font Awesome icons improve recognition and visual clarity.
 - Orange styling highlights important navigation items.

**B. Hero Section**
 - Large headline: "Enjoy Our Delicious Meal".
 - Orange accent color emphasizes the word "Delicious".
 - Short introductory paragraph communicates the restaurant theme.
 - A Book Table call-to-action button draws attention to table booking.
   
**C. Food Image Presentation**
 - A prominent food image creates a visual focal point.
 - The image is sized to fit the right side of the hero layout.
 - A rotating animation adds movement and makes the hero section more dynamic.
   
**D. Background and Visual Design**
 - Full-screen background image creates the restaurant atmosphere.
 - A dark transparent overlay improves text readability.
 - Orange and white form the main color palette.
 - Flexbox is used to align the navigation and hero content.

**E. Animation**
 - CSS @keyframes rotates the featured food image continuously.
 - The animation uses a linear timing function for consistent rotation.
